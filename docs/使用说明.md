# Skill Wallet 0.6.4

纯本地 Windows 技能钱包。本次修复：信息栏上下光效统一使用图片主色；导入自动跳过相同卡牌，避免不同内部编号、时间或收藏状态造成重复。

## 启动与升级

新用户：解压完整文件夹，双击 `SkillWallet.exe`。需要 Windows 10 / 11 和 .NET Framework 4.8，无需账号、服务器或 API 密钥。

同一个技能库已经打开时，再次双击 EXE 会直接显示原窗口；原窗口最小化时会恢复。

旧用户：先关闭旧版，把本包里的 `SkillWallet.exe` 和 `SkillWallet.exe.config` 复制到原程序目录，替换同名文件。**保留原来的 `data` 文件夹和 `portable.mode`**。也可从旧版导出 `.skillpack`，在新版导入。

## 导入去重

相同卡牌会自动跳过，即使内部编号、创建时间、收藏状态或图片文件名不同。导入包内部的相同卡牌也只处理一次。整个包都已存在时只显示跳过提示，不改动技能库和备份。

同一张卡牌的正文、图片或其他内容有修改时，仍提供冲突选择，默认保留本机版本；也可以选择使用导入版或两份保留。再次导入已经保留的同一副本不会继续新增。已有的重复卡牌保留原样，可在管理模式手动选择整理。

## 浏览与管理

- 浏览模式：拖动或滚轮翻牌，点击卡牌复制正文，卡牌上的 `⋯` 查看详情。
- 页面右上角 `⋯` 进入管理模式，卡牌连续展开为一排，摆正并提亮；“完成”或 Esc 收回。
- 管理模式：点击勾选，直接短划浏览。无论卡牌是否被选中，都可以短划，因此全选后也能滑动浏览。
- 按住卡牌约 350 毫秒，会抬起并显示移动数量，再拖动进行排序。长按已选卡牌移动整个选中组；长按未选卡牌只移动该卡牌。
- 按住期间先移动超过约 8 像素会进入浏览，取消本次长按。长按后没有移动就松手，不改变顺序。
- 排序时其他卡牌平滑让位，并显示插入位置；拖近左右边缘会渐进滚动。松手保存，Esc 取消本次排序。
- “全选”包含当前筛选结果里屏幕外的卡牌。筛选内排序保留隐藏卡牌的位置；切换筛选时取消不再可见的选择。
- 批量删除先确认数量；删除与排序完成后，右下角提供一次“撤销”，也可用 Ctrl+Z。撤销限当前会话中的上一次删除或排序，后续数据修改会替换或清除撤销记录。

窗口变宽时，两侧连续露出更多真实卡牌，远处逐渐回正。最小窗口为 640×520：宽度收窄后显示一张主卡和两张侧卡；高度收窄后标题说明、数字与翻页按钮收起，保留小圆点。搜索、分类和工具可通过紧凑入口访问，管理模式仍保留选择、删除与完成。齿轮仅在导入、导出或音效因窗口缩小而隐藏时出现，菜单只列出被收起的功能；功能都在外面时齿轮隐藏。撤销保留在原来的位置。技能库到达首尾时不重复卡牌填充空位。

## 图片与自动配色

新建或编辑时可添加 PNG / JPG 图片，每张 Skill 最多 12 张，每张图片最多 12 MB、4000 万像素。

自定义封面按完整图片等比适配，避免裁切和信息面板遮住底部；留白按图片背景衔接。

第一张添加的图片默认作封面，也可指定其他图片、取消封面或移除图片。未设置自定义封面时保留默认图。图片保存在技能库内部，随导出、导入和备份迁移。

卡牌信息区采用深色文字底，顶部光斑和明艳底边统一使用图片主色，LED 提取封面主色及少量次色；没有自定义封面时从默认封面取色。灰度图使用中性光。按钮、菜单、开关均为黑灰白，不跟随封面变色。换封面不会修改正文。

详情中点击图片可放大：滚轮缩放，拖动平移，双击或点击“适应窗口”复位，“100%”查看原始像素，Esc 关闭并返回原详情。

## 动效与音效

滑动、悬停、按压和管理过渡默认启用，不再提供“滑动反馈”开关。仅保留“滑动音效”滑轨，默认关闭。开启后只在卡牌滑过切换位置时播放机械短音；即使窗口未激活，鼠标悬停滚动翻卡也保留音效；普通按钮、复制、勾选、排序操作和开关本身均无声。窄矮窗口可在右上角齿轮中控制。

音效开启时会提前准备播放通道，启动本身无提示声；关闭释放音频设备。若仍无声，可查看 data/audio-errors.log 中的初始化错误。实际听感及原故障电脑需复测。

设置保存在 data/preferences.json，导出技能库不改变其他电脑的音效设置。旧版关闭的滑动反馈设置将不再限制动效。

上下 LED 均有缓慢移动和呼吸，顶部适度加强，主色和少量辅助色均来自封面。0.6.1 将底部全部彩色光层的强度在 0.6.0 基础上降低 20%，顶部和卡牌自身光效保持不变。无地板、倒影和落地阴影。系统关闭界面动画时保留静态光效；最小化停止背景光更新。排序过程暂时保持灯光颜色，落位后再过渡。

## 复制失败处理

本版使用 Windows Unicode 剪贴板接口，短暂占用时进行最多 7 次异步重试。连续点击复制会取消过时的重试，以最新一次为准。

仍然失败时显示真实错误码，打开完整正文，可全选手动复制、重试或保存为 TXT。诊断信息写入 `data/clipboard-errors.log`，只记录时间、错误类型、错误码和次数，不记录 Skill 正文。此改进不能保证解除其他软件持续占用剪贴板的问题。

## 数据与本地自动成卡

粘贴整段提示词，通过本地规则整理名称、简介、分类和标签，正文原样保存，不执行提示词、不联网调用模型，也不生成效果图片。复杂内容可在编辑中微调。

便携模式数据为 `data/我的技能库.skillpack`。整个目录复制或使用导入 / 导出都可迁移；保存采用原子替换并保留上一份 `.bak`。支持旧版 v1 / v2 技能库，图片总量最多 128 MB / 2048 张不同图片，最多 5000 张卡牌、16 MB JSON 正文。

当前不提供加密、云同步和历史版本管理。程序未做代码签名。
