# Skill Wallet 0.6.4 源码

Windows WPF / .NET Framework 4.8。纯本地运行，无账号、服务器或运行时网络请求。

## 构建

在源码目录执行 powershell -ExecutionPolicy Bypass -File .\build.ps1。默认生成相邻 SkillWallet-v0.6.4，可传 -OutputDirectory。使用 Windows Framework64 编译器。封面、品牌 PNG 和九尺寸 ICO 全部嵌入 EXE，不依赖素材绝对路径。品牌素材处理说明和提示词见 Assets/branding-notes.md。

## 0.6.4 调整

信息栏顶部光斑和底边均使用封面主色，保留原深浅层次。LED 仍可使用少量图片辅助色。

导入先生成统一 ImportPlan，预览数量和最终处理共用同一计划。内容一致时忽略内部 ID、创建/修改时间、收藏状态、标签顺序、图片文件名及平台换行差异；正文空白和图片内容不被抹平。同 ID 有修改，或同名称同正文但图片/版本/分类等有差异，均作为冲突；名称相同但 ID 和正文不同的独立 Skill 保留为新增。冲突默认保留本机版本，用户仍可选择覆盖或两份保留；跨 ID 覆盖保持本机 ID、收藏和创建时间。再次导入已保留的冲突副本不会继续复制。整个包重复时只提示已跳过数量，不重写技能库/备份，不重建卡牌。现存重复卡牌不会被自动删除。

本轮 143 项检查通过：归档/本地规则/图片及导入数据测试 70、导入 UI 4、UI 21、Polish 30、图片 UI 6、封面配色 12。包含独立生成默认库、整包/包内重复、三种冲突模式、重复副本、图片差异、收藏时间差异、预览不修改源、重复导入不改文件。已渲染核对信息栏上下同为蓝色。

## 0.6.3 调整

自定义封面使用完整等比适配，图片区域结束于信息区上边缘，不再被信息区遮住；空隙按图片角落底色衔接。内置封面保持原构图。取色按色相族聚合并按有效面积加权，避免小面积高饱和点缀挤掉主体色；底边、主光和少量辅助光使用同一封面配色，换封面及恢复默认均同步更新。

移除可见窗口失焦时的滑动音效屏蔽；窗口未激活时滚轮翻卡也有声音，静音与最小化仍生效。重复启动按技能库路径定位已有 HWND，授权原进程切到前台并发送唤回消息；恢复原窗口及其对话框，不再显示重复启动弹窗，不新开实例。不同技能库仍独立运行。

本轮 135 项检查通过：交互 19、UI 21、Polish 30、Design 21、图片 6、管理 17、运动 5、用户蓝色海报回归 11、真实双进程唤回 5。另验证 WaveOut 静音准备及 15 个缓冲块，渲染核对封面底部完整、主光和卡牌底边蓝色。未进行主观听音验收。

## 0.6.2 调整

只保留卡牌实际切换位置的滑动音效，移除普通按钮、复制、勾选、长按排序起止和开关试音。短音来自用户提供视频中的机械卡点（约 52 ms，素材说明见 Assets/slide-tick-notes.md），嵌入 EXE。重复选择当前分类直接返回，不重建筛选控件或卡牌、不重置位置、不叠截图。复制成功时始终显示小尺寸深灰圆角“已复制”提示，1.35 秒后淡出，连续复制更新同一提示。

本轮 91 项检查通过：专项交互 16、UI 21、Polish 30、管理 17、运动 7；另验证 WaveOut 静音准备并处理 15 个缓冲块。专项检查覆盖重复分类对象不变、只在滑动时请求音效、复制提示出现/连续刷新/自动消失。未通过模型主观听音评估，实际音色以用户视频提取采样为准。

## 0.6.1 调整

## 本版结构

- MainWindow.cs / CarouselMotion.cs：连续惯性卡牌流、同一全卡圆角裁切和遮光、两行标题、深色信息区和彩色底边。远处卡牌逐渐回正。
- Responsive.cs：640×520 最小窗口、宽高独立响应、阈值回差、矮窗口收起说明和数字控件但保留圆点、窄窗口三卡和紧凑搜索/分类/工具菜单。菜单从按钮位置展开，内容不缩放。
- Management.cs / Interaction.cs：展平管理、350ms 长按单张/整组排序、短划浏览、边缘滚动、删除/排序撤销。排序保存直接更新现有卡牌索引，不重建控件、不叠旧截图。
- Palette.cs：内置或自定义封面采样、饱和代表色及次色；排除灰白背景，灰度图保持中性。信息板为不透明渐变，正文区域深色以保留对比度，明艳颜色集中底边。没有手动配色项。
- Visuals.cs：无地板的暗色背景，连续光晕、轻微黑色纹理减轻暗部色阶，顶部更宽、底部较强。主次色来自同一封面、缓慢错相移动，拖拽排序时暂时保持色彩。系统关闭界面动画时使用静态光效。
- UI.cs / Feedback.cs / Dialogs.cs：中性黑灰白控件、字形及字重层级、悬停/按压、圆形勾选、统一暗色确认和提示。移除滑动反馈开关，动效默认开启；仅保留记忆状态的音效开关。
- SoftSound.cs：只在音效开启时启动后台 WaveOut PCM 通道，先静音准备，不播放开机声。52ms 视频原声机械卡点，65ms 限频；静音缓冲保持通道准备，关闭开关释放设备，失败重试并记录不含正文的 audio-errors.log。API 依据：https://learn.microsoft.com/en-us/windows/win32/api/mmeapi/nf-mmeapi-waveoutwrite
- Branding.cs / wallet.ico：透明卡牌星芒用于页首，黑底圆角图标用于标题栏/任务栏/EXE。
- SingleInstance.cs：按技能库互斥锁键标记窗口，重复启动直接恢复并激活已有实例。
- ImportPlan.cs：语义去重、包内去重和统一导入预览/冲突处理，不清理已有卡牌。
- Models.cs / Pictures.cs：v1/v2 归档、图片去重、限额、原子保存与备份。打开旧库不重写文件。
- Editor.cs / LocalDraft.cs：单框本地规则整理提示词，原文不变；完整编辑、图片和封面选择。不是本地大模型，不自动生成图片。
- ClipboardSupport.cs：原生 Unicode 剪贴板、7 次异步重试及 TXT/手动备用；ImageViewer.cs：图片放大、缩放和平移。

## 验证

检查必须使用独立 --data-dir，不能指向真实用户技能库。隐藏检查不捕获实体鼠标、不写系统剪贴板、不播放声音。

参数：--self-test <目录>；--ui-check、--management-check、--motion-check、--picture-check、--polish-check、--design-check、--interaction-check、--import-check <报告文件>。设计检查覆盖三卡响应、选择保持、排序对象保留、色彩与文字对比度、灰度封面、按钮配色和菜单。

用户海报回归：--cover-check <报告> --cover-image <蓝色主体、橙色点缀海报路径>，可与 --render 合用；仅用于独立测试目录，不保存测试样本。

截图：--render <PNG>，可加 --showcase、--many、--manage、--new、--edit-preview、--detail、--compact、--tiny、--short、--narrow、--wide、--tools-preview、--copy-preview。--error-file 指定检查错误输出。

0.6.0 基线 147 项检查通过，v1/v2 旧库打开后哈希不变。已核对普通、展平管理、640×520、小高度、窄长、宽屏、工具菜单、新建面板截图。另用静音设备探针验证本机 WaveOut 首次创建成功且连续处理缓冲。

测试边界：静音设备探针不等于主观听音验收；原来出现音效或剪贴板故障的电脑仍需实际复测。未覆盖每种声卡、输出设备切换、显卡、DPI 和实体鼠标手感。界面默认调用系统字体，无额外字体安装。
